# Security Guard Overtime Invoice Audit

Validate billed guard hours, overtime, holidays, post coverage, qualifications, and contractual bill rates.

**Primary buyer:** Enterprises, campuses, and property portfolios. **Evidence:** security contracts, post orders, schedules, time punches, guard credentials, regular and overtime rates, holidays, vacancies, incidents, invoices, and credits.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Security contract library
- Post order registry
- Guard credential validation
- Schedule ingestion
- Time punch matching
- Regular hour calculation
- Overtime responsibility
- Holiday premium audit
- Vacant post detection
- Supervisor markup control
- Incident coverage validation
- Invoice recalculation
- Vendor dispute workflow
- Credit reconciliation
- Location post analytics

Run `./start.sh`, then open <http://127.0.0.1:4725>. API: `5725`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
